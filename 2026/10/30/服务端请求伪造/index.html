服务端请求伪造（SSRF）

权威定义（CWE-918）

CSRF、SSRF 和 XXE 三者的核心区别如下：

漏洞类型 被借用的对象 请求从哪里发出 核心攻击目标 核心防御手段
CSRF（跨站请求伪造） 已登录用户的浏览器 用户的电脑 借用浏览器自动附带的 Cookie，冒充用户本人执行转账或改密操作 校验 Anti-CSRF Token、配置 SameSite 属性
SSRF（服务端请求伪造） 存在漏洞的 Web 服务器 机房里的服务器 借用服务器的内网位置，穿透防火墙访问内网系统或本机服务 限制服务器访问内网网段、校验域名白名单、单次解析绑定 IP
XXE（XML 外部实体注入） 服务端的 XML 解析器 机房里的服务器 解析 XML 中的 SYSTEM 外部实体时，读取本地文件或触发 SSRF 请求 在 XML 解析器中禁用 DTD 与外部实体

为什么外部电脑直接访问不到内网IP

地址类别 常见地址范围/掩码 通俗含义与常见风险
本机回环地址 127.0.0.1 服务器自己。很多管理员为了安全，会让数据库或管理服务只监听127.0.0.1，以为外人连不上。通过ssrf让服务器访问127.0.0.1就能直接连上这些本机服务
局域网私有地址 A类：10.0.0.0/8B类：172.16.0.0/16C类：192.168.0.0/24 企业内部机房与办公网专用网址，其中172.17.0.1是docker容器默认的宿主机网桥地址
云服务元数据地址 169.254.169.254（阿里云：100.100.100.200） 公有云主机（阿里云、腾讯云）获取自身内部配置和临时管理密钥的固定内部地址
全零地址 0.0.0.0 再linux系统中，当程序向0.0.0.0发起请求时，系统自动送到本机的127.0.0.1上。常被用来绕过针对127.0.0.1的简单过滤

IP地址变形与黑名单局限：进制转换、缩写与自定义域名

变形方式 127.0.0.1的等价写法 转换规则
八进制写法 http://0177.0.0.1/ 在数字前面加一个0。系统就会按八进制来计算。八进制的0177换成十进制的等于127（164+78+7=127）
十六进制写法 http://0x7f.0.0.1或合并写http://0x7f000001 在前面加0x，系统就按十六进制计算。十六进制的0x7f换算成十进制等于127（7*16+15=127）
纯十进制大整数 http://2130706433/ 把127.0.0.1对应的32位二进制数直接转成一个完整十进制大整数
省略中间的零 http://127.1 当中间段全是0时，可以不写，127.1会被系统自动补充为127.0.0.1
全零地址替代 http://0.0.0.0或http://0/ 在liunx系统下，访问0.0.0.0或0会被默认转到本机的127.0.0.1
